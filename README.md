## 🧪 Hands-On Cybersecurity

Practical learning is an important part of my development. I work with controlled lab environments to explore security concepts, investigate vulnerabilities, and understand how security testing works.

Areas of practical exploration include:

- **Kali Linux:** Practising security tools and command-line workflows.
- **Metasploitable 2:** Exploring intentionally vulnerable systems in an isolated lab.
- **Network reconnaissance:** Learning host discovery, port scanning, and service identification.
- **Vulnerability discovery:** Practising identification, validation, and documentation of weaknesses.
- **Web application security:** Exploring testing techniques and common web vulnerabilities.
- **Authorized exploitation:** Learning how vulnerabilities behave in deliberately vulnerable lab systems.
- **Security analysis:** Studying network traffic, logs, alerts, and system behaviour.

All offensive security exercises are intended for ethical education and authorized testing in controlled environments. I respect privacy, applicable laws, and the requirement to obtain permission before testing any system.

## 🧪 Hands-On Cybersecurity

Practical experience is an important part of my development. I use controlled lab environments to explore security concepts, understand common vulnerabilities, and practise defensive analysis.

Areas of practical exploration include:

- **Kali Linux:** Learning security tools and command-line workflows.
- **Metasploitable 2:** Studying intentionally vulnerable systems in an isolated lab.
- **Network reconnaissance:** Exploring host discovery, ports, services, and network traffic.
- **Vulnerability discovery:** Learning to identify, validate, and document security weaknesses.
- **Web application security:** Practising safe testing techniques and learning common web vulnerabilities.
- **Authorized exploitation:** Understanding exploit behaviour within deliberately vulnerable lab systems.
- **Security analysis:** Examining network activity, logs, alerts, and system behaviour.

All offensive security exercises are intended for ethical education and authorized testing in controlled environments. I respect privacy, applicable laws, and the requirement to obtain permission before testing systems.
